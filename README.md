# Мой дашборд

Личная веб-страница с вкладками: Сводка, Деньги, Работа, Учёба, Время.

## Из чего состоит

| Файл | Что в нём |
|---|---|
| `index.html` | Скелет страницы: боковая панель / нижнее меню и место для содержимого |
| `css/styles.css` | Внешний вид. Все цвета светлой и тёмной темы собраны в начале файла |
| `js/app.js` | Меню, переключение вкладок, тема, общие настройки (шестерёнка), включение работы без интернета |
| `js/summary.js` | Вкладка «Сводка»: сегодня, сроки на 7 дней из всех вкладок, деньги, неделя в цифрах |
| `js/fx.js` | Анимации, конфетти, звуки, свайпы, переходы между вкладками |
| `js/weather.js` | Погода для шапки Сводки (Open-Meteo, город — в настройках) |
| `js/command.js` | Единая строка «добавить или найти» (Ctrl+K) |
| `js/reminders.js` | Напоминания: пары, дела на день, платежи, итог дня |
| `sw.js` | Работа без интернета: сохраняет копию страниц и расписания |
| `icons/` | Значки для установки на экран телефона (рисует `tools/make_icons.py`) |

| `js/ui.js` | Общие помощники: формат рублей и дат, окна-формы, подсказки |
| `js/charts.js` | Графики (рисуются сами, без сторонних библиотек) |
| `js/money-data.js` | Справочник «Денег»: категории, словарь слов, разбор быстрой строки и выписки Т-Банка |

| `js/time.js` | Вкладка «Время»: записи быстрой строкой, шаблон смен, часы по категориям за неделю |

| `tools/fetch_schedule.py` | Забирает расписание с alt.ranepa.ru. Запуск: `python tools/fetch_schedule.py 3231В` |

## Расписание

Сайт академии не даёт другим сайтам читать свои страницы прямо из браузера, поэтому расписание
забирает программа `tools/fetch_schedule.py` и кладёт в `data/schedule.json`. Пока обновлять её
нужно вручную (или попросить Claude); после выкладки на GitHub она будет запускаться сама раз в день.

## Где лежат мои данные

Файл-копия с данными лежит в папке `клод\дашборд-данные` — **вне** папки сайта, чтобы не попасть в интернет
при выкладке на GitHub. Загрузить его в браузер: «Деньги» → «Настройки» → «Загрузить из копии».
Личные суммы (части зарплаты, ставка) хранятся только в данных, а не в коде.

## Как вносить деньги

- **Быстрая строка** вверху вкладки: «такси 450», «стипендия +3200», «вчера кофе 250 нал», «5.11 продукты 1240».
  Плюс перед суммой — доход. «нал» / «карта» — с какого счёта. Незнакомое слово → откроется форма, выбор запомнится.
- **Кнопка «Запись»** — полная форма: группа, подкатегория (необязательно), счёт, дата, комментарий.
- **Импорт выписки Т-Банка**: PDF-выписка из приложения или CSV из веб-версии.
  «История» → «Импорт выписки». Повторы отсеиваются, исправленные категории запоминаются,
  выбор у одной операции применяется ко всем таким же (тот же магазин, человек или договор).
  PDF читается в браузере модулем pdf.js (подгружается с cdnjs при первом импорте), файл никуда не отправляется.
- **Копилки** («Планы»): «Пополнить» переводит деньги с карты или наличных — это не расход.
  Траты из копилки не входят в месячный бюджет. Поле «Ставка, %» — проценты в месяц и за год.
- **Разделить счёт**: в новой трате поле «👥 Разделить с друзьями» — в расходы идёт твоя доля, на друзей — долги.
- **Поездки** («Планы»): даты, бюджет, валюта и курс. Траты за даты поездки собираются сами; строка в карточке принимает сумму в валюте.
- **Бюджет на неделю** (Обзор, настройки денег): лимит на повседневные группы, сбрасывается по понедельникам.
- **Кэшбэк Т-Банка** (Обзор): подсказка, какие категории выбрать в начале месяца.
- **Капитал** (Обзор) и **тренд категории** («Итоги» → нажать на категорию).
- **Список покупок** и **стрики/достижения** — на «Сводке».

## Как открыть на компьютере

Попросить Claude запустить предпросмотр. Или самому выполнить в папке `клод`:

```
python -m http.server 8765 --directory dashboard
```

и открыть в браузере http://localhost:8765

## Где хранятся данные

Сейчас данные хранятся в браузере на этом устройстве. Позже подключим облачную базу,
и они будут одинаковыми на телефоне и компьютере. До этого стоит иногда скачивать
резервную копию: «Деньги» → «Настройки» → «Скачать копию».

## Обновление файлов

В `index.html` у файлов стоит номер версии (`?v=2`). После изменений его нужно увеличить,
иначе браузер может показать старую версию из кэша.

## На экран телефона и без интернета

Когда дашборд будет в интернете: iPhone — Safari → «Поделиться» → «На экран „Домой“»;
Android — Chrome → меню ⋮ → «Установить приложение». Открывается как приложение.
После первого открытия работает и без связи (кроме загрузки PDF-выписки — модулю чтения PDF нужен интернет).
